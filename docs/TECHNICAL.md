# 기술 설명

북미판 GRNE52(Rev 0)를 해석한 내용입니다. 주소는 실행파일(`GameUS.dol`)이 메모리에 올라간 가상 주소입니다.

## 디스크 구성

| 파일 | 내용 | 처리 |
| --- | --- | --- |
| `game/s01.pds` ~ `s27.pds` | 스테이지별 대사 | `build.py: patch_pds` |
| `game/*.res` | 맵 설명, 표지판, 보고서, 몬스터 소개, 메모리 카드 안내 | `patch_res` |
| `game/Menu.CRD`, `Menus.CRD` | 카드 이름·기술 이름 | `patch_crd` |
| `game/*.mel`, `*.Men` | 메뉴·상점·덱 편집 문자열 | `patch_mel` |
| `game/Sp.TEX` 36번 항목 | 게임 글꼴 아틀라스 | `build_sptex` |
| `game/Title.TEX`, `menu.TEX`, `WorldMap.TEX`, `load/000.gtx` | 그림 글자 | `images.py` |
| `GameUS.dol` | 실행파일 문자열, 글리프 그리기 루틴 | `dolpatch.py` |

새 ISO는 원본 ISO를 복사한 뒤 바뀐 파일만 다시 씁니다. 파일이 커져 원래 자리에 들어가지 않으면 디스크 끝의 빈 공간에 새로 배치하고 FST의 위치·크기를 고칩니다.

## 글꼴과 한글 인코딩

**원본 글꼴**
- 원본 글꼴은 `Sp.TEX` 36번 항목입니다.
- 형식은 IA4이고, 32px 칸에 Latin-1 글자가 들어 있습니다.
- 글자를 그리는 루틴은 두 개입니다(대사창용, 메뉴용). 둘 다 한 바이트 문자를 받아 아틀라스 칸 번호로 바꿉니다.

**한글 글리프 추가**
- 번역문에 나오는 한글 878자를 서울한강체 EB로 그렸습니다(4배 슈퍼샘플링, 테두리 1.4px).
- 아틀라스 아래쪽을 늘려 그 칸에 넣었습니다.

**인코딩과 그리기 루틴 수정**
- 한글 한 글자는 두 바이트로 적습니다: `0x82 + idx // 128`, `0x80 + idx % 128`.
- 두 그리기 루틴의 첫 바이트 비교 지점에 분기를 넣었습니다.
  - 첫 바이트가 `0x82` 이상이면 두 번째 바이트까지 읽어 한글 칸 번호를 계산합니다.
  - 그다음은 기존 Latin-1 경로로 돌아가 같은 방식으로 그립니다.
- 아틀라스 높이가 바뀌었으므로 텍스처 좌표 배율(k_s, k_t)을 새로 계산했습니다.
  - 새 배율은 기존 상수 블록의 쓰이지 않는 칸에 넣었습니다.
- 추가한 명령은 저메모리 빈 영역(0x80001800~)에 새 텍스트 섹션으로 넣었습니다.

## 대사(`*.pds`)

- 대사는 표 8(영어)을 씁니다. 표 9에는 다른 언어로 된 예비 사본이 있으며, 게임은 표 9를 읽지 않습니다.
- 각 대사에는 화자 이름(0x20바이트 칸)과 본문이 있습니다. 본문은 CRLF로 줄을 나누고, `@`는 주인공 이름 자리입니다.

번역문은 다음 규칙으로 정리해 넣습니다(`layout_dialogue`).
- 빈 줄로 쪽을 나눕니다.
- 한 쪽은 최대 4줄입니다. 한 줄이 칸 폭을 넘으면 어절 단위로 줄을 바꿉니다.
- `=`로 시작하는 번역은 줄바꿈을 그대로 지킵니다.

## 메뉴 문자열(`*.mel`, `*.Men`)

- 문자열은 섹션마다 문자열 풀에 모여 있습니다. 코드는 문자열을 섹션 시작 기준의 u32 오프셋으로 참조합니다.
- 번역문으로 길이가 바뀌어 문자열 위치가 밀리면 `mel_repoint`가 섹션 안의 참조 오프셋을 함께 고칩니다. 이것을 빼먹으면 이름 입력 화면의 버튼처럼 글자가 잘리거나 비어 보입니다.

## 실행파일 문자열

- `text/dolstr_all.json`에는 문자열마다 주소, 칸 크기(`slot`), 참조 위치가 있습니다.
- 참조 위치는 `lis/addi` 쌍, r2/r13 상대 로드, 포인터 표 중 하나입니다.

번역문을 넣는 방식은 길이에 따라 다릅니다.
- **칸 안에 들어가는 번역:** 그 자리에 씁니다.
- **칸보다 긴 번역:**
  1. 새 텍스트 영역에 둡니다.
  2. 참조하는 명령을 고쳐 새 주소를 가리키게 합니다.
  3. r2·r13 상대 참조처럼 명령 하나로 고칠 수 없는 곳에는 작은 분기 스텁을 둡니다.
- **4바이트 칸 문자열("No", "Use", "OK"):** 참조를 디버그 문자열 등 이미 있는 다른 칸으로 돌렸습니다. 그 칸에 "아니오", "사용", "확인"이 들어 있습니다.

`printf` 형식 문자열은 형식 지정자의 순서와 개수를 원문과 같게 유지했습니다.
- `%s`, `%d`, `*`(골라 둔 카드 장수)
- 카드 선택 확인 문구는 `*`가 13번째 바이트에 있어야 하므로 그 위치를 맞췄습니다.

## 그림 글자

`images.py`는 텍스처의 해당 칸을 지우고 한글을 그립니다.

| 대상 | 글꼴과 처리 |
| --- | --- |
| 타이틀 메뉴(`Title.TEX`) | 원본 위치와 정렬을 따릅니다. |
| 조작 안내·전투 결과 표제(`menu.TEX`) | 원본 위치와 정렬을 따릅니다. |
| 월드맵 지명(`WorldMap.TEX`) | 원본 위치와 정렬을 따릅니다. |
| 로딩 화면(`load/000.gtx`) | 원본 기울임을 흉내 내 아핀 변환을 했습니다. |
| 높이 16px 이하의 칸 | 갈무리11을 씁니다. |
| 그 밖의 칸 | 서울한강체 EB를 씁니다. |

- 그림 글자에는 가독성을 위해 1px 그림자를 넣었습니다.
- 텍스처 형식(RGB5A3·IA4 등)은 `gtx.py`가 읽고 씁니다.
