- **타이틀 메뉴·조작 안내·전투 결과·월드맵 지명·로딩 화면** 등 그림 글자

## 게임 소개 및 대상 버전

『로스트 킹덤』(일본명 『룬』)은 프롬 소프트웨어가 개발한 게임큐브용 카드 액션 RPG입니다. 북미판은 2002년 액티비전이 발매했습니다. 알란제 왕국의 공주 카티아가 다섯 왕국을 뒤덮는 검은 안개에 맞섭니다. 카티아는 룬스톤의 힘으로 카드 속 몬스터를 불러내 싸웁니다.

이 패치는 **북미판 GRNE52 (Rev 0)**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 맞는지가 중요합니다.

## 패치 적용 방법

### 1. RVZ·GCZ·CISO를 ISO로 바꾸기

xdelta는 **압축하지 않은 ISO**에만 적용됩니다. 원본이 RVZ 등 압축 형식이면 먼저 Dolphin에서 ISO로 바꿉니다.

1. Dolphin 게임 목록에서 게임을 우클릭하고 **파일 변환**을 고릅니다.
2. 형식을 **ISO**로 정하고 변환합니다.

명령줄에서는 다음과 같이 합니다.

```powershell
.\DolphinTool.exe convert -i '.\Lost Kingdoms (USA).rvz' -o '.\Lost Kingdoms (USA).iso' -f iso
```

### 2. 해시 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Lost Kingdoms (USA).iso'
```

위 표와 다르면 적용을 중단하세요.

### 3. xdelta UI로 적용

1. 릴리즈에서 `Lost_Kingdoms_GC_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Lost Kingdoms (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄로 적용

```powershell
.\xdelta3.exe -d -s '.\Lost Kingdoms (USA).iso' '.\Lost_Kingdoms_GC_KO_v1.0.xdelta' '.\Lost Kingdoms (Korean).iso'
```

결과 ISO는 Dolphin에서 그대로 실행하거나, 원하면 다시 RVZ로 변환해 보관해도 됩니다.

**세이브**
- 게임 ID는 원본과 같으므로 메모리 카드 세이브는 원본판과 함께 쓸 수 있습니다.
- 원본판에서 만든 세이브 스테이트는 쓰지 마세요.

## 한글화 범위

- **대사 429개 전체:** 오프닝, 성·마을·던전 이벤트, 전투 튜토리얼, 요정의 집, 엔딩. 화자 이름표 27종도 포함합니다.
- **카드:** 카드 273종의 이름·기술 이름·속성 표기.
- **맵·보고서·몬스터 소개 문자열 360개:** 스테이지 설명, 표지판, 몬스터 프로필, 메모리 카드 안내.
- **메뉴 문자열 106개:** 덱 편집·정렬, 상점, 시스템·옵션, 2인 대전, 이름 입력 화면 버튼.
- **실행파일 문자열 115개:** 전투 메시지, 확인 창, 카드 입수·사용 알림, 요정 관련 대사, 남은 카드 수 표시.
- **그림 글자:**
  - 타이틀 메뉴(새 게임·불러오기·옵션·2인 대전), "START 버튼을 누르세요"
  - 조작 안내, 전투 결과·스테이지 보너스 표제
  - 월드맵 지명 20여 곳과 로딩 화면 글자
- **글꼴:**
  - 게임 글꼴(대사·메뉴) 한글 878자는 서울한강체 EB로 그렸습니다.
  - 아주 작은 그림 글자에는 갈무리11을 썼습니다.
- **원문 유지:** 로고, 저작권 표기, 쓰이지 않는 디버그 문자열.

## 알려진 한계

**길이 제약**
- 실행파일 안의 짧은 문자열 일부("No"·"Use"·"OK")는 원래 자리가 좁습니다. 그래서 한글 문자열이 있는 다른 자리를 가리키도록 참조만 바꿨습니다.
- 카드 이름과 메뉴 문자열은 원래 칸 크기에 맞추느라 일부를 줄여 적었습니다.

**확인 범위**
- Dolphin에서 직접 플레이하며 다음 화면을 확인했습니다.
  - 타이틀, 이름 입력, 오프닝, 성 대사, 룬스톤 이벤트, 전투 튜토리얼
  - 덱·카드·몬스터 정보, 시스템·옵션·불러오기, 월드맵, 로딩 화면, 초반 전투
- 다음은 데이터가 한국어로 바뀐 것만 확인했습니다.
  - 상점, 전투 결과, 스테이지 보너스 화면
  - 중반 이후 대사, 2인 대전
- 실기에서의 동작은 확인하지 못했습니다.

문제가 있으면 이슈로 알려 주세요.
